# 指定星期与小时周期

在定时任务窗口中：

- **自选星期**：选择一个或多个星期，填写当天的执行时刻。例如周二、周五 14:30。
- **指定星期内间隔**：选择星期、当天起始时刻和重复间隔。例如周一、周三，从 09:00 开始每 2 小时执行，时间为 09:00、11:00、13:00……23:00。

间隔按选中日期的起始时刻对齐，任务启动稍晚不会逐次漂移。过午夜后结束当天的周期，在下一个选中日期重新从起始时刻开始。休眠期间不唤醒机器；恢复后在允许的日期及时段最多补执行一次，再计算未来时间，不批量补跑。并行与阻塞策略、所属道友、工作目录和运行模式照常适用。

## 修改任务与提醒

选中已保存任务，点击**修改任务**，或双击、按 F2。修改执行伙伴、命令、工作目录、周期或执行方式后，点击**保存修改**（Ctrl+S）。任务 ID 和旧运行记录保持不变，新设置用于后续执行；取消不改动原任务。

提醒支持**修改提醒**、双击或 F2；调整文字、时间、星期和提示方式后点击勾号或 Ctrl+S 保存，取消可丢弃草稿。停用中的提醒修改后仍然停用。

悬浮任务列表的伙伴、创建时的伙伴选项，即可查看实际生效的 Claude 程序及配置路径，区分角色专属、全局和默认配置，不显示配置文件内容。“周一至周五”“周六至周日”按固定星期执行，不含法定节假日调休。
