# 隐私与配置

- 公开版本使用独立的 %LOCALAPPDATA%/agent-pal 状态目录和对应注册表设置，不覆盖旧版目录。
- 本地保存角色、位置、定时任务的目录/提示词及历史内容；这些均可能敏感。
- 外置人物放在 %LOCALAPPDATA%/agent-pal/Characters，不放入安装目录；热更新只读取本地角色配置与PNG，不自动联网下载或执行插件。人物人设会用于AI提示词，请只导入信任的来源。
- Claude CLI 的凭据、模型、服务地址、权限由用户现有配置管理，本项目不捆绑 API 密钥。
- 安装、静默安装、升级和卸载均不改写 Claude 全局或项目配置。原生交互任务只读取所选配置，在 AgentPal 私有任务目录生成独立的会话配置，通过 `--settings` 加载该次任务的 Hooks，原文件字节保持不变。CLI 退出时删除临时配置；进程异常中断可能留下临时文件。旧版本已写入的 Hooks 不会自动清理。
- 其他本机 Claude 会话的采集默认关闭，需用户主动开启。自己的任务会标记归属避免重复记录。
- 主动 AI 发言、AI 路线、历史上的今天会调用 CLI，可能联网并消耗额度。
- 拖入文件只准备路径和需求；发送后 CLI 会按照你的权限读取/处理相关文件。
- 本项目没有另设分析遥测服务器，但 CLI、MCP 或用户配置的服务可有独立网络行为。
- 卸载只移除启动项和快捷方式，Claude 配置及旧 Hooks 保持原样，不递归删除安装目录；程序文件及可能存在的用户文件保留，关闭卸载窗口后可自行检查清理。不会回收其他 Claude 任务。

公开截图、日志前务必遮盖用户名、内网地址、文件路径、提示词和模型输出。

会话配置采用 Claude Code 官方支持的 [`--settings`](https://code.claude.com/docs/en/cli-reference) 参数。

“收集其他 Claude 会话”只决定是否接收已有桥接发来的事件；新开的外部 CLI 会话需要另行配置桥接，开启此开关不会自动安装 Hooks。
