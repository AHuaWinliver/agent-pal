# AgentPal 1.0.0

AgentPal 是连接已有 Claude Code 的 Windows AI 桌面伙伴，让对话、任务与日常陪伴融入桌面。

本次更新基于 **XianPal 0.6.13 Preview**。

## 主要变化

- **右键快捷启动**：在桌面或当前文件夹向指定伙伴派发任务，使用其绑定的 Claude 程序与配置。
- **更多伙伴与角色定制**：新增行者悟空和小白龙，支持角色包与合集导入、图片创建向导和伙伴管理。
- **更灵活的定时安排**：任务与提醒支持指定星期、按间隔重复和修改已有计划。
- **更清晰的伙伴对话**：气泡对话呈现结构化回复与执行过程，按伙伴归集记录，并显示运行异常。
- **统一的 AgentPal 体验**：更新产品品牌，优化安装流程、托盘菜单和日常窗口交互。

## 改进与修复

- 提升伙伴动作的自然度、连贯性与显示稳定性。
- 改善任务执行、状态显示、错误提示和历史记录的一致性。
- 安装、升级与卸载保持已有 Claude 配置不变。
- 更新中英文文档与角色定制指南。

## Agent 协作（实验性）

支持团队任务、依赖调度、并行执行与失败交接。此功能仍在完善，建议在监督下试用。

## 下载与使用

- 安装包：`agent-pal-1.0.0-Setup.exe`
- 源码：`agent-pal-1.0.0-Source.zip`
- 校验文件：`SHA256SUMS.txt`

本次发布面向 **Windows**，需自行配置 Claude Code。Windows 11 原生右键扩展使用项目预览签名，部署要求见[原生菜单说明](../NATIVE-MENUS.zh-CN.md)。
