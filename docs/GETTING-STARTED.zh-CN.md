# 开始使用agent-pal

## 1. 安装桌面程序

从 [Releases](https://github.com/AHuaWinliver/agent-pal/releases) 下载 Windows 安装包。若尚未发布安装包，可按仓库 README 从源码构建。

自行构建时建议将源码放在类似 `C:\src\agent-pal` 的短目录，避免 .NET Framework 的传统路径长度限制。安装/快捷方式专项测试默认使用独立的临时短目录，不会修改真实开始菜单。

安装器面向当前 Windows 用户运行，创建开始菜单快捷方式。普通安装、静默安装、升级和卸载均不改写 Claude 配置。原生交互任务通过 `--settings` 加载独立的会话临时配置，不向全局或项目 settings 追加 Hooks。程序未签名，运行前请核实下载来源与 SHA256。

安装窗口分为品牌介绍、安装设置、进度操作及功能预览区。五位伙伴集中在一页，其他页面介绍对话、文件夹任务、定时任务与 Agent 协作；约每 7 秒轮播，也可手动切换。交互安装至少展示约 6 秒，完成后停留，点击**打开 AgentPal**启动。

## 2. 接上本机 Claude Code

先在普通终端验证你自己的 Claude Code 能正常启动、访问期望的模型服务并完成授权。agent-pal不替你安装 CLI，不捆绑账号、密钥或模型，也不绕过目录信任与权限提示。

右键伙伴进入功能菜单，设置默认工作目录，然后打开对话或本机 CLI。AI 请求按 CLI 的配置发出，可能访问云端或你配置的内网服务。

## 3. 选择日常相处方式

- 右键选择青衡、绯笺、苍芷或小墨，调整大小、漫游、尾迹及主动 AI 行为。
- 双击回复气泡展开动态，查看和选择文本，也可以继续回复。
- 拖动角色可重新摆放，靠近边缘可吸附；隐藏后从托盘菜单恢复。单击托盘图标即可打开与右键伙伴相同的设置菜单。
- 主动发言、AI 路线、趣味介绍和休息提醒均可按需启用；会调用 AI 的选项可能消耗额度。
- 在默认设置中调整伙伴大小；右键菜单可减少动画，或切换“收集其他 Claude 会话”；默认仍不收集其他会话。
- 在新建文字对话框底部，点击“历史上的今天”，让当前角色按自身口吻介绍当天的历史事件。

## 4. 拖入文件，先确认再执行

将文件或文件夹拖给伙伴，确认工作目录与处理需求后再发送。动画不删除原文件，但发送后的文件读写由 CLI 权限和你的请求决定。先用测试目录验证，勿自动授权来源不明的文件和提示词。

## 5. 定时任务与提醒不是同一件事

| 功能 | 用途 | 执行方式 |
| --- | --- | --- |
| 每日提醒 / 倒计时 | 提醒你去做某件事 | 角色演出或提示框，不自动代替你完成事项 |
| Claude Code 定时任务 | 在指定目录让 CLI 执行任务 | 支持按星期重复或固定间隔，可阻塞或并行，并保留运行历史 |

任务和定时提醒都支持 **周一至周五（周一至周五）**、**周六至周日（周六和周日）** 和 **自选星期**。选择自选星期后，可同时勾选多个日期，例如每周一、三、五。

创建定时任务后检查目录、运行模式、周期和权限。原生 Background 等选项需要你的 CLI 支持对应能力。电脑休眠时程序不会唤醒电脑，恢复后按现有调度逻辑检查到期任务；不应把它当作无人值守的系统级任务保证。

## 6. 安装和更新自己的角色

右键伙伴 → **切换伙伴 → 打开角色资源目录**，将完整人物包复制进去。程序会自动发现新角色，并热更新当前角色的有效资源；无需重新安装。未出现时点“刷新角色资源”。角色包需要配置、动作PNG和校验清单，不能只放一张原画，详见 [资源包热更新教程](CHARACTER-PACKS.zh-CN.md)。

## 常见边界

- 没有配置 CLI：仍可查看角色、动作和本地提醒，但不能凭空获得模型回复。
- 看到权限或信任确认：在 CLI 内自行审阅并处理，不建议为便利全局关闭安全机制。
- 中文 / emoji 或虚拟桌面异常：提供脱敏后的 Windows 版本、缩放、字体和 CLI 版本，见 [问题反馈](https://github.com/AHuaWinliver/agent-pal/issues)。
- 卸载不会递归删除用户可写的安装目录，程序文件及可能存在的用户文件需自行审阅后清理。
